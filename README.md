# Power Plant Uptime Calculation Example

This Python script demonstrates how to calculate the estimated operational uptime of a power plant. It considers total energy capacity, daily consumption, and scheduled maintenance days, crucially rounding down the result for conservative planning.

## Language

`python`

## How to Run

Save the code as `power_plant_uptime.py` and run it from your terminal using: `python power_plant_uptime.py`
